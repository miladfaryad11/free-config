# 🔥 PRX11 - Free Config Collector

این مخزن به‌طور خودکار و در بازه‌های زمانی منظم (هر ۶ ساعت)، کانفیگ‌های پروکسی رایگان از پروتکل‌های **VLESS**، **VMESS**، **Trojan**، **Shadowsocks** و **Fragment** را از منابع و کانال‌های تلگرامی جمع‌آوری، پالایش و منتشر می‌کند.

## 🚀 نحوه‌ی استفاده

### موبایل (Android / iOS)
- **V2RayNG / Nekobox / Hiddify / Streisand**: یکی از لینک‌های بالا را در قسمت **اشتراک (Subscription)** وارد کنید. برنامه خودکار دریافت و به‌روز می‌کند.
- **Shadowsocks / Outline**: از لینک **Shadowsocks** استفاده کنید.

### دسکتاپ (Windows / macOS / Linux)
- **V2RayN / Qv2ray / Clash Verge**: لینک را به‌عنوان **Remote Subscription** اضافه کنید.
- **Clash / Sing-box**: از محتوای فایل **همه‌ی پروتکل‌ها** استفاده کنید.

### مرورگر
- از لینک **همه‌ی پروتکل‌ها** در افزونه‌هایی مثل **SwitchyOmega** یا **FoxyProxy** استفاده کنید.

## 📌 نکات مهم

- **به‌روزرسانی خودکار**: فایل‌ها هر **۶ ساعت** یکبار بازتولید می‌شوند.
- **نام‌گذاری کانفیگ‌ها**: نام هر کانفیگ شامل **نام کانال + پرچم کشور + پروتکل + تأخیر** است؛ مثلاً `PRX11 | @proxystore11 🇩🇪 VLESS 120ms`.
- **منابع**: کانفیگ‌ها از منابع عمومی و **کانال‌های تلگرامی** فعال جمع‌آوری می‌شوند.
- **کیفیت**: کانفیگ‌های نامعتبر، تکراری و جعلی حذف می‌شوند و بقیه بر اساس کیفیت و کشور مرتب می‌شوند.
- **تعداد**: هر فایل پروتکل حداکثر **۱۰۰۰ کانفیگ** دارد؛ فایل «همه» بدون محدودیت است.
- **تنوع کشوری در Hiddify**: کانفیگ‌های Hiddify به‌طور متوازن از کشورهای محبوب (آلمان، هلند، فرانسه، ترکیه، امارات، آمریکا و…) انتخاب می‌شوند.
